combine_gifs.py
  Combines three pre-made animated GIF files horizontally into one GIF.

combine_pngs_normalized.py
  Assembles an animated GIF from folders of PNG snapshots (gstep_*_expert_load.png),
  sorting frames by step number.

Summary
  combine_gifs.py is simpler and wraps existing GIFs.
  combine_pngs_normalized.py builds the GIF from raw PNG snapshots. The
  "normalized" in the name is aspirational -- the normalization logic is
  present but unused.

The repo used the gif (compare_lb_strategy_heatmaps.gif) 
which was generated by running 
python combine_pngs_normalized.py
that creates combined_heatmaps_normalized.gif
